Política de privacidad · Privacy Policy

Gerard Studio Tools · Última actualización / Last updated: 18-11-2026

1. Qué datos se usan

Al conectar una cuenta de TikTok, la herramienta recibe, con el permiso explícito del titular: el identificador de la cuenta, el nombre visible, el nombre de usuario, la foto de perfil, estadísticas básicas (seguidores, vídeos, me gusta) y un token de acceso para subir y publicar vídeos en esa cuenta.

2. Para qué

Solo para mostrar qué cuenta está conectada, subir y publicar el contenido del propio titular y ver las estadísticas de sus publicaciones. No se usan para publicidad ni se venden ni se ceden a terceros.

3. Dónde se guardan

En un servidor privado del propietario (no en la nube de terceros), con acceso restringido. Los tokens se guardan solo para poder publicar; al desconectar la cuenta dejan de usarse y se borran a petición del titular.

4. Tus derechos

Puedes revocar el acceso en cualquier momento desde los ajustes de TikTok (Seguridad → Aplicaciones con permiso) o pidiendo la eliminación de tus datos en abre una incidencia en GitHub / open a GitHub issue.

English summary

When a TikTok account is connected, with the account holder's explicit consent, the tool receives the account ID, display name, username, avatar, basic statistics and an access token used to upload and publish videos to that same account. Data is used only to identify the connected account, publish the owner's own content and show post statistics. It is never sold, shared or used for advertising. Data is stored on the owner's private server; when the account is disconnected it is no longer used and is deleted on request. Access can be revoked at any time in TikTok settings or by writing to abre una incidencia en GitHub / open a GitHub issue.
