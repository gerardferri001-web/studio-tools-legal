1. Qué es

Gerard Studio Tools («la herramienta») es una aplicación privada que su propietario usa para programar y publicar su propio contenido en sus propias cuentas de TikTok, YouTube e Instagram mediante las API oficiales de cada plataforma.

2. Quién puede usarla

Solo su propietario y las cuentas que él administra. No se ofrece a terceros ni se venden accesos.

3. Uso de las plataformas

Todo el contenido se publica respetando las condiciones y normas de la comunidad de cada plataforma (incluidas las de TikTok). El propietario es responsable del contenido que publica.

4. Sin garantías

La herramienta se usa «tal cual», sin garantías de disponibilidad. Puede dejar de funcionar si cambian las API de las plataformas.

Estos términos pueden actualizarse; la fecha de arriba indica la versión vigente. Contacto: abre una incidencia en GitHub / open a GitHub issue.
